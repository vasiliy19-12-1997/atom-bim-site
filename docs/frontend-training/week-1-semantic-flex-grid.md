# Неделя 1: две задачи по твоему проекту (atom-bim-site)

Ниже только **2 задачи**, как ты и попросил:
1) семантическая + адаптивная вёрстка;
2) уверенный flex/grid.

---

## Задача 1 — Семантическая и адаптивная вёрстка страницы `LibraryPage`

**Где делать:** `src/pages/LibraryPage/ui/LibraryPage/LibraryPage.tsx` + `LibraryPage.module.scss`.

### Что сделать

Собери страницу из семантических блоков:
- `<main>` для контейнера страницы;
- `<header>` с заголовком и описанием;
- `<section>` для «Популярные материалы»;
- `<section>` для «Новые материалы»;
- внутри секций список карточек через `<ul>/<li>`.

### Адаптив (обязательно)

Сделай 3 брейкпоинта:
- **mobile**: `<= 767px`;
- **tablet**: `768–1023px`;
- **desktop**: `>= 1024px`.

Требования:
- на mobile всё в 1 колонку;
- на tablet 2 карточки в ряд;
- на desktop 3 карточки;
- длинный текст не ломает карточки.

### Как проверить себя

- Открой DevTools и проверь ширины: `360`, `768`, `1280`.
- На каждой ширине нет горизонтального скролла.
- Структура читается в DOM как осмысленная семантика (а не набор `div`).

### Definition of Done

- Есть корректная семантика страницы.
- Адаптив стабилен на 3 размерах.
- Визуально страница не «сыпется» при длинных заголовках.

## Задача 2 — Прокачка flex/grid на реальной сетке карточек

**Где делать:** та же `LibraryPage` (чтобы не распыляться).

### Что сделать

Сделай 2 уровня раскладки:

1. **Верх страницы (header-блок)** через **flex**:
   - слева: заголовок + подзаголовок;
   - справа: кнопка `Добавить материал`;
   - на mobile кнопка уходит вниз и занимает 100% ширины.

2. **Сетка карточек** через **grid**:
   - `grid-template-columns` меняется по брейкпоинтам;
   - одинаковая высота карточек;
   - кнопка/ссылка внутри карточки «прилипает» к низу (через flex внутри карточки).

### Обязательные технические условия

- Используй `gap`, а не `margin`-хаки для расстояний между карточками.
- Для вложенных элементов используй `flex` осознанно (например, вертикальная компоновка карточки).
- Не смешивай хаотично `grid` и `position:absolute`, если это не нужно.

### Как проверить себя

- Переключи 3 размера экрана и убедись, что:
  - flex-контейнер хедера корректно перестраивается;
  - grid-сетка меняет число колонок;
  - карточки одной высоты;
  - CTA-кнопка внизу карточек на одном уровне.

### Definition of Done

- Ты можешь объяснить, **почему** здесь flex, а **почему** grid.
- В коде нет «магии» с фиксированными высотами, которые ломаются от контента.
- Поведение устойчивое на мобильном и desktop.
